# Rocket — VPN/прокси-клиент для Windows

Клиент для Windows в стиле Shadowrocket (iOS): та же сетка ячеек, крупный
переключатель подключения и нижняя панель вкладок. Построен на
[Tauri 2](https://tauri.app) (Rust) с ядром [sing-box](https://sing-box.sagernet.org)
1.14 и отдельным ядром [amneziawg-go](https://github.com/amnezia-vpn/amneziawg-go)
для AmneziaWG.

## Установка

Скачайте `Rocket_0.1.0_x64-setup.exe` из [Releases](../../releases) и запустите.
Один запрос UAC — установщик ставит приложение в `Program Files` и регистрирует
службу-помощник `RocketVpnSvc`. Дальше VPN поднимается **без запроса прав
администратора**.

Удаление — через «Параметры → Приложения» (или «Программы и компоненты»):
установщик снимает службу и чистит все свои данные.

## Возможности

### Протоколы

| | |
|---|---|
| VLESS | + Reality, uTLS-отпечаток, flow `xtls-rprx-vision` |
| VMess | alterId, ws / grpc / http транспорт |
| Trojan | |
| Shadowsocks | все шифры sing-box |
| SOCKS5 / HTTP | обычные прокси |
| Hysteria, Hysteria2 | обфускация salamander, лимиты полосы |
| TUIC v5 | congestion control |
| WireGuard | импорт `.conf` (wg-quick) |
| **AmneziaWG** | обфускация junk-пакетами (`Jc/Jmin/S1–S4/H1–H4/I1–I5`) — через своё ядро |

### Добавление серверов

- Ссылки `vless://` `vmess://` `trojan://` `ss://` `socks://` `hysteria2://`
  `tuic://` и т.д. — по одной на строку
- URL подписки (с автообновлением, по умолчанию раз в 12 ч; трафик и срок
  берутся из заголовка `Subscription-Userinfo`)
- Файл: конфиг Xray / v2ray / sing-box (JSON) или WireGuard/AmneziaWG `.conf`
- Серверы группируются как в оригинале: «Local Servers» + сворачиваемая группа
  на каждую подписку

### Поделиться сервером

Правый клик по серверу → **Share**: ссылка, JSON (Xray-формат), QR-код,
сохранение конфига в файл.

### TUN на всю систему без прав администратора

Единственный режим захвата — TUN (перехватывает весь системный трафик, никакой
ручной настройки прокси). Служба `RocketVpnSvc` работает под `LocalSystem` и
поднимает туннель, а GUI остаётся под обычным пользователем. Общение между ними —
по локальному именованному каналу с ограниченным ACL.

Если служба не установлена (например, запуск из исходников) — при подключении
приложение один раз просит UAC и перезапускается с правами администратора.

### Маршрутизация — три переключателя во вкладке «Конфиг»

- **Российские сайты без VPN** — домены и IP России (`geosite:ru` + `geoip:ru`)
  идут напрямую, всё остальное — через туннель. Российский DNS (Яндекс
  `77.88.8.8`) резолвит `.ru` мимо туннеля. Альтернатива — режим **Global**
  (весь трафик через прокси).
- **Обход через zapret** — читает hostlist'ы из папки
  [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
  (`lists/list-*.txt`) и пускает эти домены (YouTube, Discord, Twitch…) мимо VPN,
  чтобы DPI-обход zapret работал на реальном соединении. Папка ищется
  автоматически на Рабочем столе / в Загрузках.
- **Загрузки без VPN** — Steam, Epic, Battle.net, GOG, Ubisoft, EA, Rockstar и
  торрент-клиенты (qBittorrent, uTorrent, Transmission, Deluge…) качают напрямую
  на полной скорости, минуя туннель (правило по имени процесса).

Все три работают и для **AmneziaWG**: служба поднимает его как обычный сетевой
интерфейс (без захвата маршрута по умолчанию), а sing-box заворачивает в него
трафик выборочно (`bind_interface`) — маршрутизацией по-прежнему занимается
sing-box, так что правила применяются одинаково для любого протокола.

### Резервное подключение (fallback)

Настройки → **Резервное подключение**: если туннель поднялся, но интернета нет,
клиент сам переключается на другой сервер (сначала с наименьшим пингом).
Фоновый watchdog проверяет связь каждые 45 секунд и переключается после двух
неудач подряд.

### Пинг серверов

Пинг сервера на его строке в списке: для активного (подключённого) сервера —
реальный URL-тест через прокси (`/proxies/proxy/delay` в clash API, работает
для всех протоколов включая AmneziaWG); для отключённого WireGuard/AmneziaWG —
ICMP до эндпоинта (его UDP-порт не потестировать иначе). «Тест соединения» на
главной (как в оригинале) — кнопка, обновляющая пинг всех серверов сразу, без
отдельного индикатора.

### Прочее

- Интерфейс на русском и английском (переключается в Настройках), ошибки тоже
  переведены
- Автозапуск при входе в систему (стартует свёрнутым в трей)
- Системный трей: свернуть — в панель задач, закрыть (крестик) — в трей; меню
  трея Подключить/Отключить · Открыть · Выход
- Живая статистика отдачи/загрузки + лог ядра во вкладке «Данные»
- Окно всегда открывается по центру (позиция не запоминается)

## Как это устроено

```
GUI (обычный пользователь)                Служба RocketVpnSvc (LocalSystem)
  Tauri 2 / WebView2                         именованный канал
  вкладки: Home / Config / Data / Settings   \\.\pipe\rocket-vpn-svc
        │                                          │
        ├── строит конфиг sing-box ───────────────►├── запускает sing-box.exe
        │                                          │   (TUN 172.19.0.1/30, clash API)
        │                                          │
        └── для AmneziaWG: raw .conf +             └── 1) поднимает amneziawg.exe как
            конфиг sing-box с bind_interface            обычный интерфейс (без захвата
                                                          маршрута по умолчанию)
                                                      2) запускает sing-box поверх —
                                                         его outbound «proxy» просто
                                                         привязан к этому интерфейсу
```

- **sing-box** (bundled, `src-tauri/binaries/sing-box.exe`) — основное ядро и
  единственное, что принимает решения о маршрутизации. Конфиг генерируется в
  `singbox.rs`, TUN только IPv4 (`172.19.0.1/30`, mtu 1500, `stack: mixed`), DNS
  `strategy: ipv4_only`.
- **amneziawg-go** (`src-tauri/binaries/amneziawg.exe` + `wintun.dll`) — для
  AmneziaWG: sing-box не умеет обфускацию junk-пакетами, поэтому шифрование и
  junk-обфускацию делает это отдельное ядро. Служба конфигурит его через
  UAPI-пайп (ключи base64→hex, junk-параметры), ждёт рукопожатия, затем
  прописывает интерфейсу обычный `0.0.0.0/0` с высокой метрикой (не сплит
  `/1`+`/1` — тот бы забрал весь системный трафик независимо от метрики) —
  этого достаточно, чтобы sing-box своим outbound `{"type":"direct",
  "bind_interface":"RocketAWG"}` мог выборочно заворачивать в него трафик, а
  остальная система продолжала ходить через настоящий шлюз.
- **Служба** (`rocket-service/` → `rocket-svc.exe`) — Windows-служба на
  `windows-service`. Многоэкземплярный именованный канал (поток на подключение),
  обработчик защищён от паники.

### Раскладка репозитория

```
src/                        фронтенд (vanilla JS + Vite, без фреймворка)
  views/{home,config,data,settings}.js
  api.js                    обёртка над командами Tauri (+ mock для браузера)
  i18n.js                   словари ru/en
src-tauri/src/
  parser.rs                 разбор ссылок / подписок / JSON-конфигов
  singbox.rs                генерация config.json для sing-box
  core.rs                   процесс sing-box + опрос трафика (clash API)
  service.rs                клиент именованного канала службы
  elevate.rs                UAC-элевация (raw FFI)
  store.rs                  JSON в %APPDATA%\Rocket
  lib.rs                    команды Tauri, трей, обвязка, fallback
rocket-service/src/main.rs  привилегированная служба (sing-box + AmneziaWG)
src-tauri/binaries/         sing-box.exe, amneziawg.exe, wintun.dll, rocket-svc.exe
```

## Сборка из исходников

Нужно: Node.js 18+, Rust (stable-msvc) + MSVC Build Tools + Windows SDK,
Go 1.24+ (только если пересобирать `amneziawg.exe`), WebView2 (есть в Windows 11).

```bash
npm install
./scripts/fetch-singbox.sh          # или: pwsh scripts/fetch-singbox.ps1
npm run tauri dev
```

`npm run dev` без Tauri открывает интерфейс в браузере с mock-данными (без
проксирования).

Установщик:

```bash
npm run tauri build
```

→ NSIS-установщик в `src-tauri/target/release/bundle/nsis/`.
`build:all` перед сборкой ещё собирает `rocket-svc.exe` (`scripts/build-svc.mjs`).

## Где лежат данные

| Путь | Что |
|---|---|
| `%APPDATA%\Rocket\store.json` | серверы, подписки, настройки |
| `%ProgramData%\Rocket\` | рабочий `config.json`, `cache.db`, логи ядра, `awg.log` |

Rule-set'ы `geosite-ru` / `geoip-ru` скачиваются с GitHub при первом подключении
и кэшируются в `cache.db`.
